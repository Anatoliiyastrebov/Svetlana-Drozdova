# Health Questionnaire App (Анкета по здоровью)

Многоязычное веб-приложение для сбора анкет по здоровью с политикой обработки персональных данных (ФЗ-152), интеграцией с Telegram и поддержкой двух языков (RU, EN).

## 🚀 Возможности

- ✅ Многоязычный интерфейс (Русский, Английский)
- ✅ Политика обработки персональных данных (ФЗ-152)
- ✅ Интеграция с Telegram Bot API для отправки анкет
- ✅ Четыре типа анкет: для младенцев, детей, женщин и мужчин
- ✅ Автосохранение данных в localStorage
- ✅ Валидация форм
- ✅ Адаптивный дизайн

## 📋 Требования

- Node.js 18+ и npm
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- Telegram Chat ID (получить у [@userinfobot](https://t.me/userinfobot))

## 🛠️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd anketazdoroyou-main
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка переменных окружения

Создайте файл `.env.local` в корне проекта:

```env
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_CHAT_ID=your_chat_id_here
```

**Важно:** Не коммитьте файл `.env` в репозиторий! Он уже добавлен в `.gitignore`.

### 4. Запуск dev-сервера

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`

## 📦 Сборка для продакшена

```bash
npm run build
```

Сборка выполняется Next.js для деплоя на Vercel.

## 🌐 Деплой на Vercel

### Настройка переменных окружения на Vercel

**КРИТИЧЕСКИ ВАЖНО:** Переменные окружения должны быть заданы в Vercel до деплоя/пересборки.

#### Пошаговая инструкция:

1. **Перейдите в настройки проекта на Vercel:**
   - Откройте ваш проект в Vercel
   - Перейдите в **Settings** → **Environment Variables**

2. **Добавьте переменные окружения:**
   - Нажмите **"Add New"**
   - **Для первой переменной:**
     - **Key:** `TELEGRAM_BOT_TOKEN`
     - **Value:** `your_bot_token_here`
     - Выберите окружения (Production, Preview, Development)
     - Нажмите **"Save"**
   - **Для второй переменной:**
     - **Key:** `TELEGRAM_CHAT_ID`
     - **Value:** `your_chat_id_here`
     - Выберите окружения (Production, Preview, Development)
     - Нажмите **"Save"**

3. **ОБЯЗАТЕЛЬНО пересоберите сайт:**
   - Перейдите в раздел **Deployments**
   - Нажмите на три точки у последнего деплоя → **Redeploy**
   - Дождитесь завершения сборки (может занять 2-5 минут)

4. **Проверьте результат:**
   - Откройте сайт в браузере
   - Откройте консоль разработчика (F12)
   - Проверьте, что предупреждение о переменных окружения исчезло
   - Попробуйте отправить тестовую анкету

**Важно:** Если вы видите ошибку "Telegram is not configured on server", это означает, что:
- Переменные не были добавлены правильно, ИЛИ
- Сайт не был пересобран после добавления переменных

**Решение:** Убедитесь, что переменные добавлены правильно и пересоберите сайт.

## 🔧 Технологии

- **Next.js** - фреймворк и serverless API routes

- **TypeScript** - типизация
- **Tailwind CSS** - стилизация

## 🔐 Безопасность

- Файл `.env.local` с токенами не должен попадать в репозиторий
- Токен Telegram хранится только на сервере (API routes)
- Токены Telegram Bot API должны храниться в безопасном месте
